# Preformal A2 applicability addendum

Version: `A-CORE-SCOPE-20261015-v1.0`. Frozen before any formal A1/A2 result.
This is an explicit clarification added during integration, independently reviewed;
the original A_CORE plan did not specify this exact type applicability algorithm.
Original global A1 thresholds, population, molecule split and twenty shuffles remain
unchanged. This addendum operationalizes the limited-type scope clause in §3.5.

After applying the unchanged GLOBAL A1 gate, evaluate each frozen training type
with the same cell-equal, paired Core/Type/shuffle block-bootstrap calculation and
exact same gate: at least1000 paired cells, ten nonempty1000µm blocks and1900/2000
valid draws; Core−Type mean at least0.01nats/molecule with CI lower bound>0;
Core−matched shuffle CI lower bound>0. Same fixed seeds and fold/donor rules apply.
These are applicability screens, not independent tissue/owner validation or a
replacement global scientific gate. A positive type never rescues a negative global A1.

A2 candidates must satisfy the original A1 cell eligibility plus membership in
established training types. Every candidate at a pixel must meet the same scope;
GT/GTC/SHUFFLED abstain together otherwise. Record the applicable type indices,
per-type coverage and intervals, scope status and excluded coverage. Unknown,
invalid-reference and insufficient-Core cells retain their original exclusions.

Global GO_A2 with no established type yields INCONCLUSIVE_SCOPE. If A2 is otherwise
admitted and fits its budget, it still runs the four fixed arms with no eligible
transfers; identity/zero-action is a legal complete result, not evidence of global
owner correction. Scope is never relaxed after observing outcomes.

A2 adoption estimates therefore concern this established subset and its coverage;
whole-field own-QC/capture/P/N, native comparison, same-domain controls and all
frozen guardrails remain mandatory. Report this restriction rather than present
results as an unqualified whole-population Core effect.
